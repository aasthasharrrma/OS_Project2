# Project 2: Bank Simulation

Compile and run with:

```sh
javac Project2.java
java Project2
```

The program starts three teller threads and fifty customer threads. It uses Java semaphores for the opening barrier, customer line, teller/customer handshakes, door capacity, manager, and safe.

No command-line arguments or external libraries are required. Delete generated `*.class` files before submitting source-only work.
